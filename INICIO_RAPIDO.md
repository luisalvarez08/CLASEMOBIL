# 🚀 INICIO RÁPIDO - Flutter 10 Apps

## ⚡ Ejecutar en 3 pasos

### 1️⃣ Instalar dependencias

```bash
flutter pub get
```

### 2️⃣ Verificar que no hay errores

```bash
flutter analyze
```

### 3️⃣ Ejecutar la aplicación

```bash
flutter run
```

## 🆘 Problemas Comunes

### Error: "No device found"

**Solución:** Conecta un dispositivo o inicia un emulador

```bash
flutter devices
```

### Error: "Pub get failed"

**Solución:** Verifica tu conexión a internet y ejecuta:

```bash
flutter pub get --verbose
```

### Error al compilar

**Solución:** Limpia el proyecto y vuelve a compilar:

```bash
flutter clean
flutter pub get
flutter run
```
